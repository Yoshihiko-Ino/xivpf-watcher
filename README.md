# XIVPF Watcher

[xivpf.com](https://xivpf.com/) の募集一覧を検索・監視し、条件に合う募集を通知するWindows用GUIツールです。

## 主な機能

- 募集名・本文キーワード、ジョブ、目的タグ、DCなどで絞り込み
- 「現在募集」で通知せずに検索し、人数・日本語ジョブ略称・募集詳細を確認
- PCポップアップ、ntfy、Discord Webhookによる通知
- 新規のみ／既通知を含む全件の通知モード切り替え
- 通知履歴、検索条件・通知設定の保存、ログ表示
- 45～600秒の間隔で定期監視

## 使い方

1. [Releases](https://github.com/Yoshihiko-Ino/xivpf-watcher/releases/latest) からWindows用ZIPをダウンロードし、新しいフォルダに展開します。
2. `XIVPF-Watcher-v1.11.5.exe` を起動し、「フィルタ」で検索条件を指定します。「現在募集」の「今すぐ検索」で募集を確認できます。
3. 通知する場合は「設定」で通知方法を有効にし、必要な項目を入力して「設定保存」後、「開始」を押します。監視を止めるときは「停止」を押します。

## 動作環境

- Windows 10 / 11（64bit）
- インターネット接続
- Pythonの追加インストールは不要です。

更新時は旧フォルダを残し、起動後に設定内容と「設定保存先」を確認してください。保存先に応じて、以前の設定が読み込まれます。
